## О проекте:

КакДостатьСоседа — сервис поиска человека для совместной аренды жилья.

Обычный поиск недвижимости начинается с квартиры. Здесь подход обратный:
сначала найти подходящего соседа → затем вместе найти жильё

Пользователь создаёт анкету, указывает бюджет, район, привычки и предпочтения к будущему соседу. После этого система позволяет искать подходящих людей с помощью фильтров и механизма взаимного интереса.

При взаимной симпатии создаётся общий чат, где пользователи могут обсудить условия проживания и обменяться ссылками на подходящие варианты жилья.

## Как это работает

1)Регистрация

2)Создание анкеты

3)Выбор предпочтений о соседе

4)Поиск и фильтрация анкет

5)«Мне подходит сосед!»

6)Взаимный лайк

7)Общий чат

8)Совместный поиск жилья

### Также предусмотрен обратный сценарий, если у пользователя есть жильё для сдачи:

1)«Ищу соседа»

2)Публикация объявления

3)Получение заявок

4)Обработка заявок

5)Чат
